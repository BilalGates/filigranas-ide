# Auditoría integral de Filigranas IDE tras Trama v2

22 de noviembre de 2026 · macOS 27.2.1 arm64 · base `4556da5` · rama `codex/auditoria-integral`.

## Resumen ejecutivo

Filigranas compiló y abrió en WKWebView. Con repositorios de prueba, Monaco leyó un archivo real, el terminal devolvió la carpeta del proyecto, Entrega mostró el diff de Git y Flow, Studio y Brain leyeron sus datos de SQLite. Se corrigieron defectos en el arranque, la navegación, la creación de tareas, la procedencia, las preferencias y la lectura de archivos. Se retiró una orden duplicada de Studio. La paridad visual sigue abierta. Workspace, Brain y Ajustes presentan diferencias de composición o contenido. El semáforo quedó dos puntos más arriba tras redimensionar a 960 × 600.

La arquitectura permite evolucionar el producto. React concentra navegación y presentación, y Tauri concentra persistencia, operaciones Git y procesos. Las restricciones principales son el checkout compartido sin aislamiento de escritura por ruta, las consultas por fila para construir resúmenes y la falta de fixtures visuales equivalentes de extremo a extremo. La prueba local de proveedores no equivale a una prueba operativa con cuentas autenticadas. La auditoría no asigna porcentajes de calidad o seguridad.

### Base y procedencia

- `main` limpio, cuatro commits por delante de `origin/main` local (`2edd11f`). La diferencia de árboles se limitaba a las reglas de commits y a los ajustes de Copilot. Se inspeccionaron HEAD, las ramas y seis worktrees existentes y se creó otro para la auditoría. Las PR #19, #20 y #21 incorporaron las vistas, el marco y el directorio de Inicio. El CI consultado de la punta `e24ddda` de #21 pasó en macOS, Windows y dependencias. [PR #21 y checks](https://github.com/BilalGates/filigranas-ide/pull/21/checks)
- `packageManager` y el lockfile fijan pnpm 11.13.1. Desarrollo, Tauri y CI lo invocan. Se verificó una instalación congelada en el worktree. Las referencias a npm en actas antiguas y en la detección de proyectos externos tienen un propósito vigente.
- HTML local `Filigranas · Trama.html`, SHA-256 `7e20b6e508b43c0f76c54f42da6e423ee9e9b280265f9d0767d2bf1e2d18fd38`. Incluye las siete vistas. Sus estilos incrustados difieren de las dos hojas archivadas en `design/trama-v2`. Se contrastó con [las capturas versionadas](trama-paridad/README.md). La revisión exacta del Artifact sigue por confirmar.
- La prueba nativa abrió el ejecutable de desarrollo con repositorios Git desechables, PNG sintético y perfil SQLite propio. Las capturas cubren visualmente el avatar y las cuotas de la cuenta. La instalación habitual quedó intacta.

### Agentes, Git y Jev

- `tracker`, `runs`, `tasks`, `work` e `isolate` conservan reservas, expedientes y copia de trabajo. Se verificaron concurrencia con datos sintéticos, transiciones entre tareas y sesiones, reapertura con turnos activos, relevo de worktree y bloqueo de Git durante el trabajo. Los controles internos no gobiernan la escritura de procesos externos. [Trabajo](../src-tauri/src/work.rs) · [Ejecuciones](../src-tauri/src/runs.rs) · [Relevo](../src-tauri/src/handoff.rs)
- Git serializa mutaciones del IDE y vincula aprobaciones a intención y SHA. Se comprobaron falta de checks, rechazo, SHA obsoleto y respuesta remota perdida sin PR duplicada en la prueba. Las operaciones que interactúan con GitHub en escritura quedaron fuera del recorrido. [Aprobaciones](../src-tauri/src/approval.rs) · [Publicación](../src-tauri/src/pr.rs)
- Jev local y sombra preservan el esfuerzo operativo. Activar TypeSafe requiere consentimiento y credencial del sistema. Se verificaron el catálogo y el protocolo por HTTP local y el fallback por tiempo de espera, cuota, fallo de proveedor y política. El enrutador limita consultas, restringe los modelos elegibles y registra el origen de la decisión sin el texto del encargo. Las recomendaciones de contexto son asesoría. El coste depende de tokens informados y precios disponibles. El modo activo autenticado sigue pendiente. [Jev](../src-tauri/src/jev/mod.rs) · [Transporte](../src-tauri/src/jev/typesafe.rs)

## Validación y mediciones

- La línea base pasó la instalación congelada, Vite, cinco pruebas TypeScript, 125 pruebas Rust, Clippy y diez recorridos de Chromium. Dejó diez pruebas Rust ignoradas. La rama pasó Vite, cinco pruebas TypeScript, 126 pruebas Rust y Clippy con `-D warnings`. La suite Rust ordinaria dejó diez pruebas ignoradas. Se ejecutaron además las integraciones locales de Chrome, Jev HTTP y relay de edición y revocación. Pasaron las tres.
- Se reprodujeron contra la base los fallos de acceso a Flow, alta, tema y procedencia. Pasaron las diez pruebas existentes y las seis nuevas en la última ejecución de Chromium. Un intento anterior agotó el plazo del diff en el servidor recién iniciado. Se capturaron 40 parejas de base en cinco tamaños. Se entregan las ocho parejas finales de 1440 px, dos hojas de base en tamaños estrechos y la evidencia nativa posterior. La ronda de parejas finales estrechas alcanzó el plazo en una captura del HTML.
- Compilación Tauri de desarrollo y arranque de la base y la rama. Se redujo la información de depuración del paquete local para limitar el espacio. `pnpm tauri build --no-bundle --ci` generó también el ejecutable de producción macOS, sin empaquetar ni abrir otro `.app`. La ejecución automatizada ejercitó las siete vistas, dos proyectos, lectura Git y terminal real. Después de reiniciar, Retomar recuperó `beta` y el núcleo releyó el recuerdo, las tareas y el diff. La revisión automática bloqueó las pruebas de cuentas autenticadas por consumo de cuota y envío de texto. Se solicitó autorización para un turno sintético por proveedor.
- La entrada Vite pesó aproximadamente 997 kB y 281 kB comprimidos. Monaco se carga bajo demanda. Su worker de TypeScript pesa 6,93 MB antes de comprimir. El canvas ambiental usa 1/16 de la resolución por eje, y su bucle depende de la visibilidad, el movimiento y la actividad. En un muestreo de arranque, el proceso nativo registró 118 MiB RSS y 0,5 % CPU. El proceso WebContent observado al arrancar registró 194 MiB y 1 %. En otra ejecución de desarrollo, las dos muestras desde el comienzo del documento hasta la navegación fueron 177 y 430 ms. En un proyecto de prueba, escribir 200 tareas sintéticas con 150 dependencias tomó 367 ms y pasar a Flow hasta encontrar 201 nodos tomó 84 ms. El proceso nativo registró 103 MiB RSS y 3,5 % CPU en la muestra posterior. Quedan pendientes GPU, arranque en frío, uso sostenido con agentes y retención de memoria a largo plazo.
- WKWebView registró rechazos del portapapeles de Monaco con clics programáticos de la automatización. Los recorridos continuaron y el diff se mostró. Falta repetir esa interacción con gestos físicos antes de atribuirla al uso normal.

Copilot revisó y creó estos commits locales de código en la rama de auditoría. `62fa3cc` valida la lectura, `5cfa0e9` corrige Trama, `04b5933` incorpora los recorridos de navegador y `36a7d4f` ejecuta los tests de TypeScript en CI.

### Reproducción local

Desde la raíz de la rama auditada, con pnpm 11 y Rust estable, ejecutar:

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
cargo test --locked --offline --manifest-path src-tauri/Cargo.toml
cargo clippy --locked --offline --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
```

Con `pnpm dev` y Python con Playwright y Pillow, ejecutar los recorridos de [Trama](../tests/trama_browser.py) y [auditoría](../tests/auditoria_trama_browser.py) con `--channel chrome`. El [script de paridad](../design/trama-v2/parity.py) acepta `--artifact` para el export original y `--width` para seleccionar tamaño. En macOS usar desarrollo con perfil separado y repositorios desechables. Para el semáforo, capturar a 1440 × 900, redimensionar a 960 × 600 y medir el borde de color en la captura de ventana a escala 1×.
